# A short tour of mk

This document has a few mistakes left in on purpose, so Harper has somthing to say.
Hover an underline to see what it found, or put the cursor on one and press **Ctrl+.**.

## Spelling and grammar

- Red is spelling: I recieved the the package yesterday.
- Amber is grammar: She have an unique idea, and there going to try it.
- Blue is style: In order to succeed, we must first basically begin.

Code is left alone, because it is not prose:

```rust
fn main() { let teh_valu = 42; println!("{teh_valu}"); }
```

Inline code like `recieve_msg()` is skipped too.

## The preview

| Key | Does |
| --- | --- |
| Ctrl+1 / 2 / 3 | Edit, split, preview |
| Ctrl+Shift+M | Harper's issue list |
| F8 / Shift+F8 | Next / previous issue |
| Ctrl+B / I / K | Bold, italic, link |

Tick these in the preview — the editor changes with them:

- [x] Open a Markdown file
- [ ] Fix every underline
- [ ] Add a word to the dictionary
