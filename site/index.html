mk is a standalone Markdown viewer and editor for Linux with the Harper grammar checker built in. Spelling, grammar and style are checked on your machine. There's no server, no account, and nothing else to install.

Features

✓Harper, built in

mk links Harper's engine as a library, so it isn't running a language server beside the editor. It checks spelling, grammar and style as you type, and skips code blocks, inline code and front matter.

⚡Fix issues where they are

Every underline offers Harper's fixes plus Add to dictionary, Ignore here and Turn off rule. Ignored issues stay ignored across edits and restarts. To get to them, hover an underline, press Ctrl+., or open the issues panel.

✎An editor made for prose

mk uses CodeMirror 6. Headings, emphasis, links and code are styled in place, fenced code is highlighted in its own language, and lists continue when you press Enter. It also has find and replace, multiple cursors and full undo history.

◧Live preview

The preview uses GitHub-flavoured rendering: tables, task lists, strikethrough, autolinks, heading anchors, highlighted code and front matter. It scrolls in step with the editor. Ticking a task in the preview updates the source.

⧉Tabs for several files

Open files from the dialog, the command line or by dropping them on the window. Each tab keeps its own undo history, cursor and scroll position, and a tab with unsaved changes asks before it closes.

☰A section rail

Each heading gets a dash at the edge of the page. The dash for your current section is highlighted and moves as you scroll. Click a dash to jump to that section, or hover over the dashes to see the headings by name.

↻Keeps up with the file on disk

If a file changes on disk, mk reloads it silently, or asks first if you have unsaved edits, so it works as a live viewer beside another editor. Saves are atomic and keep line endings, symlinks and permissions.

⚙Settings as plain files

You get light and dark themes and five English dialects (American, British, Canadian, Australian, Indian), and you can switch Harper's rules on or off one by one. Settings, your dictionary and ignored issues are plain files in ~/.config/mk/.

⌂At home on the desktop

Run mk notes.md from a terminal, or mk -v for a preview-only view. The installer adds mk to your file manager's “Open With” menu for Markdown files. Links to other Markdown files open in mk.

Private by default

Your text never leaves your machine. Untrusted documents are handled safely: raw HTML is sanitised and scripts can't run, local images load only from the document's own folder, and only http, https and mailto links open in your browser.

One exception: the preview fetches remote images, as a browser would. To read an untrusted file without loading them, use the editor-only view (Ctrl+1).

Build and install

You need Rust 1.85 or newer, Node 20 or newer, and the WebKitGTK packages Tauri 2 uses on Linux (libwebkit2gtk-4.1-dev, libgtk-3-dev, libsoup-3.0-dev).

git clone https://github.com/dsasante1/mk.git
cd mk
./run.sh samples/tour.md   # build once (a few minutes), then open
./install.sh               # put `mk` on your PATH and in "Open With"

Run npx tauri build instead to get a .deb and an AppImage.
